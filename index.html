Featured Case Study: FlyRank ML Ranking Pipeline

Beat 1: The Problem

Manual GSC spreadsheet audits fail to capture non-linear position vs CTR decay, causing engineers to miss high-opportunity keywords.

Beat 2: What I Did & Decided

Engineered an in-memory DuckDB query pipeline with strict zero-leakage data contracts and trained a Scikit-Learn Random Forest model on 1,200 search performance snapshots.

Beat 3: What Came of It

Achieved superior precision and F1-score gains over baseline heuristics, enabling automated prioritization via baseline_action_score.csv.

SELECT content_hash_id, priority_score 
FROM fact_daily 
WHERE gsc_impressions > 500 
ORDER BY priority_score DESC;
