# Phase: Foundations — Portfolio Identity Kit

---

## 1. Typography Selection

* **Heading Font:** **Inter** (Bold / Semi-Bold, Clean Modern Sans-Serif)
* **Body Font:** **Inter** (Regular, Highly Readable UI Standard)
* **Code / Mono Font:** **JetBrains Mono** (For SQL & Python snippets)

---

## 2. Color Palette & Hex Codes

| Element | Color Name | Hex Code | Visual Sample |
|---|---|---|---|
| **Background** | Canvas Off-White | `#FAFAFA` | Light, crisp background |
| **Primary Text** | Charcoal Ink | `#111827` | Near-black high contrast text |
| **Accent / Signal** | FlyRank Tech Blue | `#2563EB` | Subtle accent for links & CTAs |
| **Border / Muted** | Neutral Slate | `#E5E7EB` | Soft divider borders |

---

## 3. Logo & Favicon Specification

* **Favicon Symbol:** Minimalist Monogram **`[ R ]`** or **`R.I`** set in Inter Bold inside a rounded `#111827` square box with white text.
* **Header Brand Text:** `Rahman Islamzada` set in **Inter Bold (18px)** followed by a quiet dot (`.`).

---

## 4. Two-Line Style Note (Claude Project Instruction)

> **Typography & Palette:** Inter for headings/body (`#111827` text on `#FAFAFA` background) with a quiet `#2563EB` blue accent for primary actions.  
> **Mood & Aesthetic:** A minimal, high-contrast engineering aesthetic that lets code, data pipelines, and quantitative evidence remain the main focus on the page.
